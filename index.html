세상의눈 (Sesang)

세상의눈은 국내 시사 뉴스를 짧은 영상과 긴 영상으로 정리해 유튜브·틱톡 채널에 올리는 1인 채널입니다.

이 앱은 채널 운영자 본인의 유튜브 채널에 영상을 올리고 관리하는 데에만 YouTube Data API를 사용합니다.

개인정보처리방침 (Privacy Policy)

Sesang is a single-operator channel that publishes news summary videos. This app uses the YouTube Data API only to upload and manage videos on the operator's own YouTube channel.
