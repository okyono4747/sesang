개인정보처리방침

시행일: 2026-11-16

  1. 세상의눈 앱은 채널 운영자 본인 계정만 사용하는 내부 도구입니다. 외부 이용자의 개인정보를 수집하지 않습니다.

  3. 받은 인증 정보는 운영자 컴퓨터에만 저장하며 제3자에게 제공·판매하지 않습니다.

  5. 권한은 Google 계정 권한 페이지에서 언제든 해제할 수 있습니다.

Privacy Policy

The Sesang app is an internal tool used only with the channel operator's own Google account. It does not collect personal data from other users. YouTube Data API access is used solely to upload, edit and read videos on the operator's own channel. Credentials are stored only on the operator's computer and are never shared or sold. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at https://myaccount.google.com/permissions.
